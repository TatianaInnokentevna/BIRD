# BIRD
Game Menu Creation: Designed and implemented a game menu with features such as sound on/off toggle.
Game Mechanics: Developed the main game mechanic where players control a bird avoiding randomly appearing knives in a chaotic environment.
Defeat System: Created the defeat functionality, including visual effects like a bird explosion upon collision with a knife.
Final Touches: Added engaging audio features, such as a "quacking" sound and other playful elements to enhance the gaming experience.
Game Monetization: Integrated monetization elements to optimize the game for revenue generation.
This combination of functionality and creativity resulted in an engaging and enjoyable game experience for players.
